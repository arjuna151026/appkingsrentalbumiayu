🚗 King's Rental Bumiayu - Smart Car Rental Platform

Project Submission untuk #JuaraVibeCoding

King's Rental Bumiayu adalah platform penyewaan mobil modern yang dirancang untuk memberikan pengalaman pemesanan yang cepat, interaktif, dan futuristik. Website ini mengintegrasikan kecerdasan buatan (AI) untuk membantu pelanggan menemukan mobil yang tepat.

✨ Fitur Unggulan (Highlight Features)

1. 🤖 Asisten AI Cerdas (Robot Eilik): Dilengkapi dengan widget customer service AI yang interaktif dan sapaan pop-up otomatis untuk mendongkrak engagement.

2. 🎙️ Voice-to-Text Recognition: Pengguna dapat mencari mobil atau bertanya kepada AI hanya dengan berbicara melalui mikrofon (Web Speech API).

3. 👁️ Quick View Detail (Slider): Pop-up elegan bergaya modern untuk melihat spesifikasi dan galeri foto mobil (interior & bagasi) yang dapat digeser tanpa berpindah halaman.

4. ❓ FAQ Akordion & Testimoni Marquee: UI/UX mulus untuk pertanyaan yang sering diajukan dan animasi berjalan tanpa batas (infinite scroll) untuk ulasan pelanggan.

5. 🎛️ Dashboard Admin Dinamis: Panel khusus admin untuk menambah, mengedit, dan mengelola katalog armada mobil yang terhubung langsung ke database.

3. 💻 Teknologi yang Digunakan

Frontend: HTML5, CSS3 (Glassmorphism UI), Vanilla JavaScript, AOS Animation Library, RemixIcons.

* Backend: PHP (Native).

* Database: MySQL.

* AI Integration: Google Gemini API.

🚀 Cara Menjalankan Project (Localhost)

Karena website ini menggunakan PHP dan MySQL, ikuti langkah berikut untuk menjalankannya:

1. Pastikan Anda telah menginstal XAMPP.

2. Clone repository ini atau download sebagai ZIP.

3. Ekstrak folder project ke dalam direktori C:/xampp/htdocs/.

4. Buka XAMPP Control Panel, lalu jalankan module Apache dan MySQL.

5. uka browser dan akses http://localhost/phpmyadmin/.

6. Buat database baru dengan nama kings_rental_db.

7. Import file kings_rental_db.sql (yang ada di dalam repository ini) ke dalam database tersebut.

8. Buka tab baru di browser dan akses website melalui: http://localhost/nama_folder_project/index.html
